第一阶段：服务器底层指纹加固

清除云厂商机房痕迹，消除时区错乱，彻底切断 DNS 泄露源头。

# 1. 修改主机名 (请从上方表格选取对应的 Hostname)
sudo hostnamectl set-hostname fra-web-prod

# 2. 同步目标国时区 (请从上方表格选取对应的 Timezone)
sudo timedatectl set-timezone Europe/Berlin

# 3. 安装英文语言包，统一系统底层语言指纹 (全球服务器通用)
sudo apt update && sudo apt install -y language-pack-en
sudo update-locale LANG=en_US.UTF-8

# 4. [防 0 播放终极防御] 强制写入公共 DNS 并锁定，防止云厂商内网劫持
sudo bash -c 'echo -e "nameserver 8.8.8.8\nnameserver 1.1.1.1" > /etc/resolv.conf'
sudo chattr +i /etc/resolv.conf

第二阶段：网络加速与控制面板部署

开启 BBR 拥塞控制（保障视频上传/滑动流畅度），安装最兼容 Reality 协议的 3x-ui 面板。

# 1. 开启 BBR 网络加速
sudo bash -c 'echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf'
sudo bash -c 'echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf'
sudo sysctl -p

# 2. 一键安装 3x-ui 面板 (MHSanaei 稳定版)
curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh | sudo bash
防火墙严正警告： 严禁在 Linux 系统内开启 ufw 或 iptables！必须在 云厂商的 WEB 管理页面（安全组/防火墙） 中放行面板端口（如 TCP 1902）和节点流量端口（如 TCP/UDP 25888）。

第三阶段：深度 DNS 防泄露配置 (3x-ui 网页后台)

在面板后台 -> 面板设置 -> Xray相关设置 中严格按此配置：

配置项设定值核心逻辑
Fake DNS坚决关闭 (OFF)禁止返回 198.18 虚拟 IP，防止 TikTok 底层 API 嗅探出虚拟代理环境。
DNS 列表8.8.8.8, 1.1.1.1只使用最干净、通用的海外公共 DNS。
查询策略UseIPv4强制禁用 IPv6 解析，堵死 IPv6 地址导致的位置直接暴露漏洞。
并行查询开启 (ON)加快真实解析速度，弥补关闭 FakeDNS 带来的极微小首屏延迟。

* 设置完成后，务必点击底部的“保存”，并在面板设置中点击“重启 Xray 内核”。

第四阶段：节点 S 级参数设置 (VLESS-REALITY)

在面板的 入站列表 中添加节点，参数必须严格一致（打造隐身衣）：

参数项设定值核心逻辑
协议VLESS目前封锁率最低、最纯净的底层协议。
端口建议 443 或 2053伪装成标准 HTTPS 网页端口，降低 ISP 干扰。
安全REALITY借用目标国大厂真实证书，无视 DPI 深度包检测。
流控 (Flow)xtls-rprx-vision必须开启，彻底消除 TLS 握手包的长度指纹特征。
Destwww.yahoo.de:443 (示例)必须加 :443！ 请从上方【核心查询表】中选取对应国家的域名。
SNIwww.yahoo.de (示例)不加端口！ 必须与 Dest 的域名绝对一致。
uTLSchrome伪装为全球最常见的谷歌 Chrome 浏览器握手特征。
Private Key / Short ID点击 生成生成随机私钥和短 ID，确保节点唯一性。
嗅探 (Sniffing)全部开启 (勾选)开启 QUIC 和 HTTP 嗅探，精准处理 TikTok 专用的音视频流。

第五阶段：手机端环境与最终检测 (决定生死)

1. 手机网络客户端设置 (Shadowrocket / v2rayNG)

  • 全局路由： 必须设为 代理 (Proxy)。
  • DNS 设置： 强制设为 远程解析，手动指定为 8.8.8.8。
  • IPv6 设置： 在软件设置中彻底开启 禁用 IPv6。

2. 物理与系统环境准备 (TikTok App 打开前)

  • 必须拔掉中国电话卡（或使用目标国废卡）。
  • 彻底关闭系统级定位服务 (GPS)。
  • 系统语言和时区必须修改为与节点完全一致（参考核心查询表）。

3. 黄金检测标准 (开机必做)

手机连上节点后，打开浏览器访问 👉 https://ping0.cc：

  1. IP 位置： 必须是你购买服务器的城市（德/美/英）。
  2. DNS 位置： 绝对不能出现中国！ 必须显示海外机构（如 Google/Cloudflare/US/DE）。
  3. MaxMind 查验： Connection Type 显示为 Cable/DSL 为极品，ASN Type 是 ISP 其次，is_hosting 必须为 False。

🎯 只有以上检测全部绿灯通过，才可以打开 TikTok 进行注册、养号和发布视频！
